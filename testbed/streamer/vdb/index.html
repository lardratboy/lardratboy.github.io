vdb → vdag

OpenVDB volumes and points (level sets, fog and smoke from Houdini, Blender's fluid caches, VDB points, anything OpenVDB writes) to world files for the stream viewer, in this browser. A level set's inside, or a fog volume's density over a threshold, becomes solid voxels; a colour grid, if there is one, is baked onto the surface. A point grid's points become voxels as convert/'s clouds do, coloured by their Cd. Drop a saved file on the viewer, or open it there with file → open… (H shows the panels).
