vdag explorer

A world file's DAG drawn above the world it describes: every node a dot, every reference a line down to the child it names. Pick a node to see where it occurs, a cell to see its path to the root, a chunk to see the nodes its job reads. Files come from the stream viewer's file → export, or glb, ply → vdag.
